# Personal Profile Generator

A simple Python project that collects a user's name and date of birth, calculates their current age, and displays a personalized profile message.

## Features

- Collects the user's first and last name.
- Accepts the date of birth.
- Calculates age automatically.
- Displays a formatted profile message.
- Uses Python's built-in `datetime` module.

## Requirements

- Python 3.x

## How to Run

1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run:

   ```bash
   python "personal info.py"
   ```

4. Enter the requested information.

## Technologies

- Python
- `datetime` module
